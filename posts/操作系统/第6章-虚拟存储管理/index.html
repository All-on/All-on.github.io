一、虚拟存储基本概念#

1. 虚拟内存（Virtual Memory）#

  • 结合物理内存与磁盘，形成一个大容量的“逻辑内存”。
  • 程序使用虚拟地址，由操作系统与硬件（MMU）自动转换为物理地址。
  • 大小受寻址机制与磁盘容量限制。

2. 虚拟地址空间（Virtual Address Space）#

  • 每个进程拥有独立的虚拟地址空间。
  • 包括代码、数据、堆、栈、共享库等区域。

3. 虚拟页式存储管理#

  • 请求调页（Demand Paging）：仅在实际访问时调入页面。
  • 预先调页（Pre-paging）：预测并提前调入可能需要的页面。
  • 页面不在内存时触发缺页异常（Page Fault），由操作系统处理。

二、页表与地址转换#

1. 页表项（Page Table Entry, PTE）#

  • 页框号（PFN）：物理页框号。
  • 有效位（Present）：页面是否在内存。
  • 访问位（Accessed）：是否被访问过。
  • 修改位（Dirty）：是否被修改过。
  • 保护位（Protection）：读写/执行权限。

2. 多级页表（Hierarchical Page Table）#

  • 解决页表过大的问题（如32位系统页表可达512页）。
  • 例如：二级页表（页目录 + 页表）、x86-64四级页表。
  • 页表本身也可映射到虚存，按需调入。

3. 反转页表（Inverted Page Table）#

  • 系统只维护一张全局页表，记录物理页框 →（PID + 虚页号）。
  • 节省空间，但查找需哈希或链式辅助。
  • 用于PowerPC、IA-64等架构。

4. 快表（TLB）#

  • 缓存最近使用的页表项，加速地址转换。
  • 进程切换时需刷新或使用PCID/ASID标识。
  • TLB未命中时需查主存页表。

三、地址转换与缺页处理#

1. 地址转换流程#

1虚拟地址 → 查TLB → 命中则得物理地址  
2         → 未命中则查页表 → 页面在内存则更新TLB  
3         → 不在内存则触发缺页异常

2. 缺页异常处理#

  • 操作系统从磁盘调入缺失页面。
  • 若无空闲页框，则执行页面置换。
  • 若页面被修改过，需写回磁盘。

四、驻留集与置换策略#

1. 驻留集管理#

  • 固定分配：进程创建时确定页框数。
  • 可变分配：根据缺页率动态调整（缺页率高则增加页框）。

2. 置换范围#

  • 局部置换：仅从当前进程的驻留集中选择。
  • 全局置换：从所有进程的未锁定页框中选择。

3. 页面锁定#

防止关键页面（如内核代码、I/O缓冲区）被换出。通过锁定位或系统调用（如VirtualLock）实现。

五、页面置换算法#

算法 思想 特点
OPT 置换将来最久不被使用的页 理论最优，无法实现
FIFO 置换最早进入的页 可能产生Belady现象
Second Chance FIFO + 检查访问位 避免置换频繁访问的页
Clock 循环检查访问位 实际系统常用
NRU 按（访问位, 修改位）分类随机置换 简单高效
LRU 置换最久未访问的页 性能接近OPT，实现开销大
NFU 置换访问次数最少的页 LRU的软件近似
Aging 带时间衰减的NFU 更接近LRU
Working Set 置换不在工作集中的页 基于局部性原理

六、工作集模型#

  • 工作集 $W(\tau, \Delta)$：过去 $\Delta$ 时间内进程访问的页面集合。
  • 驻留集：进程实际在内存中的页面集合。
  • 目标：驻留集 ⊇ 工作集，以减少缺页。
  • 若驻留集小于工作集，则易引发抖动（Thrashing）。

七、清除策略与页缓冲#

1. 清除策略（Cleaning Policy）#

  • 分页守护进程（Paging Daemon）：定期将脏页写回磁盘，保持空闲页框“干净”。
  • 双指针时钟算法：前指针写脏页，后指针用于置换。

2. 页缓冲（Page Buffering）#

置换出的页暂存于“空闲页链表”或“修改页链表”。若再次访问可快速恢复，减少I/O开销。

八、加载控制与进程挂起#

系统负载过高时，通过挂起进程释放内存。选择挂起进程的依据：

  1. 优先级最低的进程   系统通常优先保留高优先级进程（如交互式进程、系统进程）。

  2. 阻塞或睡眠的进程   当前不处于就绪状态的进程，挂起后对系统运行影响小。

  3. 大内存占用的进程   释放其占用的页面可快速缓解内存紧张。

  4. 缺页率高的进程   表明其局部性差，频繁调页，挂起后可减少抖动（Thrashing）。

  5. 最近被激活的进程   根据局部性原理，刚被换入的进程可能短期内不会被频繁使用。

  6. 进程挂起策略：   可采用交换出整个进程或仅交换出部分非工作集页面的方式，结合系统负载和进程行为动态调整。

九、内存映射文件（Memory-Mapped Files）#

  • 通过mmap()将文件映射到进程虚拟地址空间。
  • 访问文件如同访问内存数组，延迟加载（按需调页）。
  • 支持共享映射（MAP_SHARED）和私有写时复制（MAP_PRIVATE）。
  • 用于共享库、文件I/O优化、进程间通信等场景。
